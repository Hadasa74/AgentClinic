# AgentClinic Technology Stack

## Confirmed direction

- Use TypeScript as the primary application language.
- Build a modern browser-based experience.
- Use React with Vite for the frontend.
- Use Vitest tests to validate frontend behavior.
- Run the frontend test suite from `frontend/` with `npm test` (`vitest run`).

## Deliberately undecided

The backend framework, API style, database, hosting, and authentication
technology have not yet been selected. Choose them when implementation
requirements are understood, favoring a reliable, maintainable solution that
fits the product's needs.

## Stack principles

- Prefer well-supported, widely used tools.
- Keep the application type-safe across its boundaries where practical.
- Prioritize reliability, accessibility, and a responsive interface.
- Avoid committing to infrastructure before the required workflows and data
  have been defined.
